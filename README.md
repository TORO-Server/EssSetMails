# EssSetMails

Minecraftのプラグイン"Essentialsx"のメールの数を指定した数にするためのスクリプト

この画像のように メールの数を 114514 にするためだけに作られました。

![実行例の画像](./.github/assets/sample.png)

## 使い方

下記のコマンドを実行すると result.yml が生成されます。

```rb
ruby main.rb メッセージ 送信元プレイヤー名 送信元プレイヤーUUID 送られた時間 メールの個数
```

### コマンドの説明

#### メッセージ

送りたいメールのメッセージを入力してください

#### 送信元プレイヤー名

メールを送ったプレイヤーの名前

#### 送信元プレイヤーUUID

メールを送ったプレイヤーのUUID (プレイヤーごとに決まっている固有の ID)

#### 送られた時間

時刻を表す数値 (タイムスタンプ。単位はミリ秒) で設定してください。

省略した場合は、実行したときの時刻が設定されます。

#### メールの個数

省略した場合は 1 が設定されます。
